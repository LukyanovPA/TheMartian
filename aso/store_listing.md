# TheMartian — ASO: тексты для Google Play и RuStore

Дата исследования: 2026-09-13. Лимиты: название ≤ 30, краткое описание ≤ 80, полное ≤ 4000 символов.
Все функции в текстах сверены с кодом приложения (фильтр ровер/дата/камера, зум, избранное, скачивание,
метаданные снимка: сол, земная дата, камера, освещение, панорама, стереопара; карточка ровера; кэш).
